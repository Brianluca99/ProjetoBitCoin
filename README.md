# Kurio - NFT Marketplace 🎨

Um Marketplace de NFTs moderno e funcional, desenvolvido como resolução de desafio técnico. A aplicação permite aos utilizadores explorar NFTs, gerir o carrinho de compras e simular o checkout completo de forma integrada com uma base de dados real.

## 🚀 Live Demo
**[Clique aqui para aceder ao projeto online no Netlify](https://kurioproject.netlify.app/)**

## 🛠️ Tecnologias Utilizadas
* **Front-end:** React, TypeScript, Vite, Tailwind CSS
* **Roteamento & Estado:** TanStack Router, TanStack Query
* **Back-end/BaaS:** Supabase (Autenticação Google + PostgreSQL)
* **Deploy:** Netlify

## ✨ Funcionalidades Implementadas
* **Catálogo de NFTs:** Listagem dinâmica a partir da base de dados.
* **Autenticação:** Login seguro via Google Provider (Supabase Auth).
* **Carrinho de Compras:** Adição, edição de quantidades e persistência de dados no carrinho por utilizador.
* **Checkout & Encomendas:** Geração de cotações em tempo real, simulação de taxas de rede e finalização de compra.
* **Gestão de Inventário:** Dedução automática do stock (`available`) após cada transação bem-sucedida.
* **Histórico:** Visualização de recibos e histórico de encomendas no perfil do utilizador.
